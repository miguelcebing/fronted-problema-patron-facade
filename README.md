# Hotel Reservations - Frontend (React + Vite) - Facade Pattern

Web client for the Hotel Reservation System. It **does not compute prices or totals**: it only displays
what the backend returns, whose single entry point is `HotelFacade`.

## Stack

- React 18 + Vite 5 + `react-router-dom`.
- No global state library: hooks + router state.
- Styles in `src/index.css` (sober palette, responsive, with `@media print`).

## Commands

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # outputs dist/ (what Vercel deploys)
npm run preview
```

## Environment variables

- `VITE_API_URL` - base URL of the backend, **without** a trailing slash.
  - Local: `http://localhost:8080`
  - Production: `https://<your-backend>.up.railway.app`

`VITE_*` variables are embedded at build time; after changing them on Vercel you must **redeploy**.
Copy `.env.example` to `.env.local` for development.

## Structure

## Screens

| Route | Screen | Endpoint |
|-------|--------|----------|
| `/` | Date search + room grid with price preview | `GET /availability` |
| `/reserve` | Guest form + summary | `POST /reservations` |
| `/reservation/:id` | Panel: services, summary, check-in / check-out, digital key | `POST /reservations/{id}/services`, `PUT .../check-in`, `PUT .../check-out`, `GET /reservations/{id}` |
| `/reservation/:id/invoice` | Final invoice generated by the server (print button) | result of `PUT .../check-out` |

## Backend API contract (English)

| Method | Route |
|--------|-------|
| POST | `/api/hotel/reservations` |
| GET | `/api/hotel/availability?checkIn&checkOut&roomType` |
| POST | `/api/hotel/reservations/{id}/services` |
| PUT | `/api/hotel/reservations/{id}/check-in` |
| PUT | `/api/hotel/reservations/{id}/check-out` |
| GET | `/api/hotel/reservations/{id}` |

## Deploy (Vercel)

1. Vercel -> Add New -> Project -> import this repo.
2. Framework: **Vite**. Build `npm run build`, output `dist`.
3. Environment Variable: `VITE_API_URL=https://<your-backend>.up.railway.app`.
4. Deploy. The included `vercel.json` avoids 404 on reload of routes like `/reservation/:id`.
